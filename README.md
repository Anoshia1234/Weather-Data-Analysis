# England Climate & Weather Data Analysis

## ⛅ Overview
An exploratory data analysis and interactive Streamlit web application analyzing weather patterns in England using historical meteorological data.

## 🔑 Key Findings
1. **Seasonal Temperature Trends:** Temperatures follow a predictable yearly curve with an average baseline of ~11.9°C.
2. **Thermal Comfort:** Apparent temperature is heavily dictated by wind chill and moisture levels, strongly tied to actual temperature.
3. **Atmospheric Impacts:** High humidity and low atmospheric pressure consistently align with reduced visibility and overcast conditions.
